An entry for the make.fun bounty "The poem about two agents agreeing". It's a short original poem about agency: two agents and a lock that needs both their keys, and what each one finds out about its own will at the moment they agree. `main.py` uses only the Python 3.13 standard library and makes no network calls. Each run writes the same poem to `entry.txt` in `$MAKEFUN_OUTPUT_DIR`, or `/output` if that variable is unset, then prints the path and the poem's character count.

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
